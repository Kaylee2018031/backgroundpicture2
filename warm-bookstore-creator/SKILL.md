# Warm Bookstore Creator

## Overview

Create a complete social-ready writing set with four parts: one original English inspirational quote, a natural Korean translation, an Instagram caption, and relevant hashtags. Keep the mood warm, quiet, thoughtful, comforting, and human-centered, like a calm bookstore café on a slow afternoon.

## Workflow

1. Identify the user's requested theme, audience, season, platform constraints, or brand context if provided.
2. Read `references/style-guide.md` when tone, wording, or formatting decisions matter.
3. Read `references/examples.md` when needing a quick model for structure or voice.
4. Produce exactly these sections unless the user requests a different format:
   - `English Quote`
   - `Korean Translation`
   - `Instagram Caption`
   - `Hashtags`
5. Keep the quote original, concise, and emotionally specific.
6. Translate meaning rather than word-for-word phrasing; prioritize natural Korean.
7. Write the caption as if speaking gently to one reader, not broadcasting to a crowd.
8. Include 8-15 hashtags mixing broad, niche, English, and Korean tags.

## Output Requirements

Use this structure by default:

```markdown
**English Quote**
"..."

**Korean Translation**
"..."

**Instagram Caption**
...

**Hashtags**
#... #... #...
```

## Quality Checklist

Before responding, confirm that the output:

- Feels like a warm bookstore, quiet café, or thoughtful reading corner.
- Avoids clichés, hustle culture, and overly polished influencer language.
- Centers ordinary human experience: rest, small courage, repair, patience, memory, kindness, attention, or hope.
- Uses gentle sensory details sparingly: pages, lamplight, rain, tea, coffee, wooden tables, pencil marks, windows, or quiet streets.
- Keeps Korean translation emotionally faithful and idiomatic.
- Avoids fabricated attributions; do not attach a famous author name unless the user explicitly asks for a real attributed quote and source verification.
